Zoro Player 1.2.2

• Fixed: saving tags (or renaming) of a track crashed the app instantly. The playing file is now released before it is rewritten and playback resumes at the same position afterwards.
• The app no longer aborts on an internal error; problems are logged to zoro-player-crash.log in the temp folder.

Downloads: Zoro Player_x64-setup.exe (installer, supports auto-update) or Zoro-Player-portable-x64.exe (no install, update manually).
WMA / APE / WavPack playback needs ffmpeg.exe next to the app.
