Zoro Player 1.2.1

• Much lower memory use: audio is now streamed from disk instead of being loaded into the WebView's memory, and the cover cache is capped.
• Update check and install flow from 1.2.0 (this release can be installed from inside the app).

Downloads: Zoro Player_x64-setup.exe (installer, supports auto-update) or Zoro-Player-portable-x64.exe (no install, update manually).
WMA / APE / WavPack playback needs ffmpeg.exe next to the app.
